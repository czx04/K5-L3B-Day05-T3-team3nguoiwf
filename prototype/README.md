# Prototype K3/K5

Mở `index.html` trực tiếp trong trình duyệt và chọn **Demo K3** hoặc **Demo K5**. Không cần build. CSS dùng Tailwind CDN nên cần kết nối mạng để có giao diện đầy đủ.

Đây là prototype giao diện: dữ liệu đặt chỗ, số ghế, xác nhận, đồng hồ, gửi hoàn và chuyển nhân viên đều mô phỏng; không có lời gọi AI/API và không thay đổi vé thật.

## Ảnh chú thích

- `screenshots/k3-flow.svg` — luồng hỏi lại, giữ chỗ, thẻ xác nhận và cửa sổ hoàn tác; số 1, 2, 4 tương ứng G2/G10/G11/G9.
- `screenshots/k5-refund.svg` — cảnh báo và màn xác nhận hoàn vé; số 3 tương ứng G2/G10.

Các hình là ảnh minh họa chú thích để đối chiếu với prototype khi demo; trạng thái thật trong trang có thể bấm tương tác.
